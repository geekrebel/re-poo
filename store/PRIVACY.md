# Privacy Policy — RE-Poo

Last updated: 16 August 2026

RE-Poo (Real Estate Search Helper) is a browser extension that filters and annotates
search results on Australian real-estate websites.

## Data collection

The extension does not collect, transmit, store remotely, or sell any user
data. It has no server, no analytics, and no accounts.

## What the extension stores locally

- Your settings (enabled filters, custom exclusion keywords, map pin style),
  in Chrome's extension storage, synced only through your own Chrome profile
  (`chrome.storage.sync`).
- A local cache of text extracted from real-estate listing pages you browse,
  used to decide whether a listing should be filtered
  (`chrome.storage.local`). This cache never leaves your browser.

## Network requests

The extension makes requests only to the real-estate website you are
currently browsing (for example, domain.com.au), to read public listing
pages for filtering purposes. It sends no data to any other destination.
